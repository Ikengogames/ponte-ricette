Ponte Codici Ricetta

Inserisci il codice di una prestazione così come è scritto sulla ricetta di una regione e trova il codice corrispondente nel catalogo dell'altra. Il collegamento passa dal codice del nomenclatore nazionale.

    Esempi:
    Aggiungi la tabella codici di un'altra regioneExcel, CSV o JSON

    Serve un file con almeno due colonne: il codice regionale della prestazione e il codice del nomenclatore nazionale (es. 89.50). La descrizione è consigliata. Il file viene letto solo nel tuo browser e non viene inviato a nessun server; la tabella resta salvata in questo browser e puoi scaricarla in JSON per condividerla o aggiungerla al progetto.

    Scegli un file o trascinalo qui .xlsx · .xls · .ods · .csv · .json

    Strumento indicativo. Le corrispondenze sono calcolate dai cataloghi pubblici e possono contenere errori o essere superate da aggiornamenti. Prima di prenotare conferma il codice con il CUP o con il medico prescrittore.

    Fonti: nomenclatore nazionale (Allegato 4 DPCM 12/01/2017 aggiornato); catalogo prestazioni Regione Toscana (OpenData Toscana, CC BY); nomenclatore tariffario Lombardia DGR XII/3630 del 16/12/2024; codici SISS da Open Data Lombardia – Transcodifica codici prestazioni.
